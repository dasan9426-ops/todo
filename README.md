# TODO アプリ

ブラウザだけで動くシンプルな TODO アプリです。インストールやビルドは必要ありません。

公開版: https://dasan9426-ops.github.io/todo/

## 使い方

`index.html` をブラウザ（Chrome / Edge など）で開くだけで使えます。

- 入力欄にタスクを書いて Enter か「追加」で登録（期限は任意）
- 丸いチェックで完了 / 未完了を切り替え
- タスク名をダブルクリック、または鉛筆アイコンで編集（Enter で保存、Esc でキャンセル）
- 「すべて / 未完了 / 完了済み」で表示を切り替え
- 期限切れのタスクは赤、今日が期限のタスクはオレンジで表示
- ダークモードとスマートフォンの画面幅にも対応

データはブラウザの localStorage に保存されます。同じブラウザで開けば次回も残りますが、
別のブラウザや、`file://` で開いた場合と `http://localhost` で開いた場合とでは別々のデータになります。

## テスト

`tests/test.html` をブラウザで開くと、タスク操作のロジックのテストが実行されます。

画面操作のテストも含めてすべて実行するには、ローカルサーバーで配信してから開きます
（`file://` では iframe の中を操作できないため、画面のテストはスキップされます）。

```sh
python -m http.server 8000
```

起動したら http://localhost:8000/tests/test.html を開きます。画面のテストは localStorage を使いますが、
終わると元のデータに戻します。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `css/style.css` | 見た目（ライト / ダーク、スマートフォン対応） |
| `js/todo-model.js` | タスクの追加・更新・絞り込みなどのロジック。DOM に依存しない純粋関数 |
| `js/app.js` | 画面の描画とイベント処理、localStorage への保存 |
| `tests/` | テスト一式（`harness.js` は依存なしの小さなテストランナー） |

ES モジュール（`import` / `export`）は `file://` で開くとブラウザに読み込みを拒否されるため、
通常の `<script>` で読み込み、`window.TodoModel` を通して共有しています。
